# titration-lab v2 — تغییرات بخش ۲

## اصلاح اشکال‌ها
1. **برچسب Ka/Kb در گران**: برای باز ضعیف مقدار برازش‌شده Kb است، نه Ka؛ حالا `pKb` نشان داده می‌شود.
2. **شناساگرها**: به‌جای وسط بازه‌ی رنگی، `pK_In` به‌کار می‌رود (متیل رد ۵٫۱، BTB ۷٫۰، فنول‌رد ۷٫۹، فنل‌فتالئین ۹٫۴)؛ فنول‌رد ۶٫۸–۸٫۲ (قبلاً ۸٫۴)؛ ۱۰ شناساگر به‌جای ۸ (متیل ویولت، تیمول بلو اسیدی/بازی، متیل اورانژ، …).
3. **منحنی شبیه‌ساز**: شبکه‌ی ۵۰۰ نقطه‌ی یکنواخت جایش را به شبکه‌ی تطبیقی داد (هر بازه با جهش pH > 0.05 نصف می‌شود)؛ نمودار مشتق با فرمول سه‌نقطه‌ای شبکه‌ی ناهمگن محاسبه می‌شود.
4. **نمودار کنترل E′₀**: آزمون ±2σ پرت را که خودش در میانگین و σ حساب می‌شود نمی‌بیند؛ آزمون Grubbs اضافه شد.

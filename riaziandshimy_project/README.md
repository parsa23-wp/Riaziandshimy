# آزمایشگاه ریاضی شیمی v1.0 — خانواده‌های تکمیلی (غیرآبی، آمپرومتری، ترمومتری، کارل فیشر، کولن‌سنجی، GUM) / Full delivery

## ساختار / Layout
- `index.html` — سایت اصلی (نسخه‌ی ۰٫۴ شما + تب جدید «⚗️ آزمایشگاه تیتراسیون»؛ تنها تغییرها: یک دکمه‌ی تب، یک `<section id="ti">` با iframe، و استثنا شدن تب جدید از قفل موقت دکمه‌ها هنگام بوت Pyodide).
- `titration-lab.html` — آزمایشگاه تیتراسیون (نسخه‌ی v2.2: همه‌ی امکانات v2.1 **به‌علاوهٔ خانواده‌های فاز ۲ در شبیه‌ساز** — ردوکس با کوپل‌های نامتقارن، رسوبی، EDTA، حسابگر برگشتی؛ ۶ نمونهٔ آمادهٔ جدید، جدول خطای شناساگر هر خانواده و کلید EN برای بخش جدید). **باید کنار `index.html` در همان پوشه‌ی GitHub Pages باشد.**
- `python/titration_sim/` — موتور پایتون (فاز ۱ تا ۳ + رفع محدودیت‌ها) + رابط PyQt6 با هر خانواده‌ها (README خودش را ببینید).
- `docs/` — MATH، CONTRADICTIONS، ROADMAP، CHANGELOG، و مقاله‌ی مرجع.

## انتشار / Deploy
دو فایل `index.html` و `titration-lab.html` را در ریشه‌ی مخزن Riaziandshimy جایگزین/اضافه کنید و Pages را دوباره بارگذاری کنید (کش مرورگر را پاک کنید).

## راستی‌آزمایی / What was and was not checked
- بررسی شد (موتور پایتون، با PyQt6 واقعی نصب‌شده و Qt آفسکرین): کل `pytest` شامل doctestها **۳۴۹ پاس + ۵ پرش** (۱ تست کند + ۴ doctest عمدیِ SKIP)؛ `pytest tests/ui` با ویجت‌های واقعی PyQt6 **۱۰ پاس**؛ `mypy --strict` روی ۲۵ فایل **بدون خطا**؛ پوشش **۹۴٪** (موتور ≥ ۸۲٪، رابط ≥ ۸۸٪ — هدف مشخص‌نامه: ۸۰٪/۶۰٪).
- سینتکس همه‌ی اسکریپت‌های دو HTML با node بدون خطا؛ منطق رابط بدون Qt هم جداگانه تست شد.
- **بررسی نشد (فقط روی دستگاه شما):** اجرای برنامه از نمایشگر واقعی (`titration-sim`)، مرورگر/موبایل واقعی (هم تب جدید، هم iframe) و اجرای همین دستورها روی پایتونِ شما.
- فاز ۲ (v0.8): موتورهای ردوکس/رسوبی/EDTA/برگشتی **به هر دو رابط وصل شدند**؛ محدودیت‌های قبلی (کوپل نامتقارن، تصحیح فعالیت، واکنش‌های جانبی فلز، AgCl₂⁻) رفع و مستند شد (MATH.md §§16.5–16.8، CONTRADICTIONS #17–#23). روش Fajans و فاز ۳ دستگاهی (پتانسیومتری، هدایت‌سنجی، فتومتری) هم اضافه شد.
- v0.9: ماژول `quantities.py` (تیتر/عیار/LOD/LOQ/هم‌سو/ماسک CN/کربنات/کفایت دادهٔ مقاله) + تب وب «محاسبات کمی» + خطای حباب و پارالاکس (CHANGELOG v0.9).
- v0.8.2: راه‌انداز `python -m titration_sim`، پشتیبانی پایتون ≥ ۳٫۱۰، ۸۱ خطای mypy--strict واقعی رفع شد و ادعای قبلی «mypy بدون خطا» که بدون نصب Qt گرفته شده بود، این‌بار با Qt واقعی راستی‌آزمایی شد (CONTRADICTIONS #24).
- فاز ۲ وب با مرورگر بی‌سر اجرا و با مقادیر موتور پایتون مقایسه شد (E_eq دی‌کرومات 1.262627، pAg هم‌ارزی 4.87، نتیجهٔ برگشتی 3 mmol).
- **v1.0 (این نسخه):** `engine/extended.py` (غیرآبی، آمپرومتری، ترمومتری، کارل فیشر، کولن‌سنجی، استانداردسازی، GUM، گزارش Markdown) + تب وب «غیرآبی و روش‌های ابزاری» + `.github/workflows/ci.yml` + `tests/browser/test_web_ext.py`. pKaهای EDTA با منبع اصلاح شد (CONTRADICTIONS #25).
- **راستی‌آزمایی v1.0 (در این سندباکس):** ۱۸۹ تست پایتون + ۲۹۸ doctest پاس (با اجراگر `run_tests.py` و یک stub برای `pytest`؛ **نه** با pytest/mypy/PyQt6 واقعی چون نصب نبودند)؛ تب وب با Chromium واقعی اجرا و خروجی JS با موتور پایتون مقایسه شد (OK).
